# Data Structures 2024

Data Structures Project for the 4th Semester (2023-2024), Computer Engineering & Informatics Department, School of Engineering, University of Patras.

## Description

This repository contains the source code and documentation for the **Data Structures** course project. The project involves implementing and analyzing various data structures using **C++**, focusing on both theoretical and practical applications.

## Features

- Implementation of key data structures such as:
  - Arrays
  - Linked Lists
  - Stacks
  - Queues
  - Trees
  - Graphs
  - Hash Tables
- Algorithms for searching, sorting, and traversing data structures.
- Detailed code comments to explain logic and functionality.

## Prerequisites

To run the code in this repository, you will need the following:

- A C++ compiler (e.g., GCC, Clang)
- Development environment (e.g., Visual Studio Code, CLion, or any text editor)
- C++17 or later installed

## Usage

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/ponawpsuxika/Data-Structures-2024.git
   ```

2. Navigate to the repository directory:
   ```bash
   cd Data-Structures-2024
   ```

3. Compile and run the desired C++ program:
   ```bash
   g++ -std=c++17 filename.cpp -o output
   ./output
   ```
